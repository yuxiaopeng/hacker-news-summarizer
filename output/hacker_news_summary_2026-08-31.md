## 1. 谷歌已从 Chrome 网上应用店下架 MV2 扩展，包括 UBO

**原文标题**: Google Has Removed MV2 Extensions from the Chrome Web Store, Including UBO

**原文链接**: [https://webiterate.dev/google-removed-extensions-ublock-origin-108/](https://webiterate.dev/google-removed-extensions-ublock-origin-108/)

谷歌已正式开始从 Chrome 网上应用店移除 Manifest V2 (MV2) 扩展程序，这标志着其向 Manifest V3 (MV3) 框架过渡的一个重要里程碑。此次转变的一个重大受害者是原版 **uBlock Origin (UBO)**——全球最受欢迎的广告拦截器之一，目前正被 Chrome 禁用。

这一过渡是谷歌重塑扩展生态系统的多年计划的一部分。谷歌辩称，MV3 能提供更好的安全性、隐私性和性能。然而，这一转变遭到了隐私社区的强烈批评。核心问题在于 MV3 处理内容过滤的方式：它将功能强大的“阻塞式 webRequest API”替换为限制更多的“声明式 NetRequest API”。这一变化限制了扩展程序可以应用的过滤规则数量，并将控制权从扩展程序转移到了浏览器本身。

由于原版 uBlock Origin 依赖 MV2 的功能来提供全面的过滤服务，它无法在新的规则下运行。虽然开发者 Raymond Hill 已发布了与 MV3 兼容的 **uBlock Origin Lite**，但它缺乏原版的高级功能和实时自定义选项。

目前仍在使用 MV2 扩展的用户将发现它们被自动禁用，且 Chrome 会提示用户寻找替代品。对于那些希望维持完整广告拦截功能的用户，建议切换到 **Firefox** 等浏览器（Firefox 已承诺维持对必要 MV2 API 的支持），或使用 **Brave**，后者利用内置的广告拦截功能绕过了 Manifest 框架的限制。

## 7. 智能手机LED利用AI检测隐藏摄像头

**原文标题**: Smartphone LED detects hidden cameras with AI

**原文链接**: [https://www.chosun.com/english/industry-en/2026/08/30/SBFXUIJQYZEARKP5T4FBAY25HQ/](https://www.chosun.com/english/industry-en/2026/08/30/SBFXUIJQYZEARKP5T4FBAY25HQ/)

研究人员开发出一种创新方法，利用普通智能手机的内置传感器和人工智能来检测隐藏摄像头。该系统在技术领域通常被称为 LAPD（激光辅助针孔检测），它利用智能手机的飞行时间（ToF）传感器或 LED 闪光灯来识别非法偷拍设备。

该技术基于逆向反射原理工作。当智能手机发出光脉冲时，光线会从隐藏摄像头的镜头上反射并直接回传至光源。由于镜子、珠宝或金属螺丝等许多常见物体也会反射光线，该系统采用深度学习人工智能模型来分析这些反射。人工智能经过训练，能够从背景“噪声”中辨别出摄像头镜头独特的光学特征。

在实验环境下，这种人工智能驱动的方法表现出的准确率显著高于人工检查或现有的商用探测器。通过将普通的消费级硬件转化为专业级安全工具，这一进步为个人在酒店客房、更衣室和出租房等敏感环境中保护隐私提供了一种便携且易用的方式。
