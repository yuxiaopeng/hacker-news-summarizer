**原文标题**: Do House members' stock trades beat the market? A test of 8,900 trades

**原文链接**: [https://arkanumdata.com/research/house-trades](https://arkanumdata.com/research/house-trades)

Arkanum Data 的这篇文章分析了 2021 年至 2023 年间美国众议院议员进行的约 8,900 次股票交易，旨在确定国会议员的投资组合表现是否优于大盘。

**核心发现：**
*   **跑赢大盘：** 研究结论显示，众议员作为一个整体确实跑赢了市场。平均而言，他们的交易相对于标普 500 指数 (SPY) 产生了约 1.1% 的年化超额收益 (Alpha)。
*   **党派差异：** 数据揭示了两党之间的表现差距。在研究期间，民主党议员的表现显著优于共和党同僚，尽管两个群体通常都获得了正收益。
*   **顶尖表现者：** 虽然报告认可了南希·佩洛西等备受关注的交易者，但它强调，跑赢大盘的现象在众议院中广泛存在，而非仅限于少数几个人。
*   **行业焦点：** 交易活动高度集中在科技和能源领域。许多交易的时间点往往与重大立法里程碑或政府合同的授予相吻合，这引发了关于“信息优势”的质疑。
*   **方法论：** 研究人员采用了“跟单交易”模拟，计算如果投资者在政治家披露交易的瞬间进行同步跟投会发生什么。尽管受到《股票法案》(STOCK Act) 规定的强制披露延迟影响，这些“模仿型”投资组合的表现依然经常优于大盘。

**结论：**
研究结果表明，众议院议员在股票市场上拥有统计学上显著的优势。这一数据为当前关于是否应禁止国会议员交易个人股票的伦理辩论增加了实证分量，旨在防止潜在的利益冲突和内幕交易观感。

## 2. 厄尔尼诺现象原理简析 [视频]

**原文标题**: A short explainer on how El Niño works [video]

**原文链接**: [https://www.youtube.com/watch?v=7_JF3etiAv8](https://www.youtube.com/watch?v=7_JF3etiAv8)

所提供的内容似乎是标准的YouTube法律声明和页脚信息，而非视频的实际转录文本。不过，基于标题“关于厄尔尼诺现象运作原理的简短解释”，以下是这一科学现象的简要总结：

**厄尔尼诺现象简介**

厄尔尼诺是一种重要的气候模式，其特征是中东赤道太平洋海域的海面温度出现周期性变暖。它是被称为“厄尔尼诺-南方涛动”（ENSO）这一更大规模循环中的“暖位相”。

这一过程通常始于信风的减弱或转向。在正常年份，信风强劲地从东向西横跨赤道吹拂，将温暖的表层海水推向亚洲和澳大利亚，从而使寒冷且营养丰富的深层海水在南美洲沿岸上升（涌升）。在厄尔尼诺期间，这些暖水则向东涌向美洲。

这种海洋温度的转变扰乱了全球大气环流，导致显著的天气变化：
*   **美洲地区：** 通常降雨量增加，导致美国南部和秘鲁等地区发生洪涝。
*   **东南亚和澳大利亚：** 通常面临比正常情况更干燥的气候，往往导致干旱和森林火灾风险增加。
*   **全球影响：** 由于太平洋面积巨大，释放到大气中的热量会提高全球平均气温，并改变大西洋和太平洋的飓风季节。

厄尔尼诺现象通常每二至七年发生一次，持续时间从九个月到两年不等，对全球农业、渔业和经济产生深远影响。

## 3. “笨鸟”实为误称：乌鸦的决策速度比人类更快。

**原文标题**: 'Birdbrain' Is a Misnomer. Crows Make Decisions Faster Than We Can

**原文链接**: [https://www.nytimes.com/2026/11/15/science/birdbrain-crows-birds-research-decision.html](https://www.nytimes.com/2026/11/15/science/birdbrain-crows-birds-research-decision.html)

发表在《科学》杂志上的最新研究挑战了历史上对鸟类智力的忽视，证明了乌鸦处理视觉线索和做出决策的速度比人类及非人灵长类动物快两倍。这项针对两只名为Lemmy和Iggy的小嘴乌鸦的研究，首次对鸟类决策的神经速度进行了量化。

在19世纪和20世纪的大部分时间里，鸟类因其大脑结构微小且看似简单，被认为在认知上较为低下。然而，在过去的20年里，科学界已经意识到鸟类的大脑结构异常复杂。此前的研究已表明，鸟类可以使用工具、计数，甚至能分辨癌细胞与非癌细胞。

特别是鸦科动物（包括乌鸦和渡鸦在内的家族）展现出了高水平的认知能力，例如：
*   解决抽象问题并为未来做规划。
*   自我识别。
*   “心理理论”，即理解并对他人的心理状态做出反应的能力。

神经科学家迈克·科隆博指出，这些发现应该能有效终结将“鸟脑子”（birdbrain）作为贬义词的用法。研究证实，尽管体积微小，鸟类大脑处理信息的速度却能超过“了不起的”人类，这证明鸟类的智力远不止是为了生存而产生的专门适应性。

## 4. MacBook Pro 的 OLED PWM 问题

**原文标题**: The MacBook Pro's OLED PWM problem

**原文链接**: [https://macanorak.com/the-macbook-pros-oled-pwm-problem-when-a-better-display-becomes-worse-to-use/](https://macanorak.com/the-macbook-pros-oled-pwm-problem-when-a-better-display-becomes-worse-to-use/)

苹果在 MacBook Pro 中引入的“PROLED XDR”（串联 OLED）显示屏在赢得技术赞誉的同时，也引发了关于显著身体不适的报告。尽管该显示屏提供了卓越的对比度和亮度，但越来越多的用户报告出现了头痛、眩晕、恶心和眼部疲劳等症状，这主要归因于脉冲宽度调制（PWM）技术。

PWM 是一种通过屏幕快速闪烁来控制亮度的技术。实验室测试显示，新款 OLED MacBook Pro 的闪烁频率为 240Hz，远低于上一代 Mini-LED 机型测得的 14,880Hz。尽管苹果结合使用了 PWM 和直流（DC）调光技术，但较低的频率对于那些对光线调节敏感的人来说依然存在问题。

文章强调，PWM 敏感度因人而异；甚至一些此前从未遇到过问题的长期 OLED 用户，也对这一特定方案表现出了不适。这表明，色彩和对比度上的技术卓越并不一定等同于所有用户的视觉舒适感。

苹果长期以来对辅助功能的承诺让人看到了一丝希望。作者指出，最近为 OLED 屏幕的 iPhone 和 iPad mini 引入的“显示脉冲平滑”（Display Pulse Smoothing）功能，可能作为一种基于软件的缓解方案被引入 Mac。

归根结底，本文发出了一个警告：尽管 MacBook Pro 拥有旗舰地位且价格高昂，但其显示屏对部分专业人士来说可能无法使用。建议潜在买家进行充分测试，因为对其他 OLED 设备的适应性并不代表能兼容新款 PROLED XDR 显示屏。目前，旧款 Mini-LED 机型仍是该系列产品中唯一的无闪烁替代方案。

## 5. Eclipse Mosquitto – 开源 MQTT 代理

**原文标题**: Eclipse Mosquitto – An open source MQTT broker

**原文链接**: [https://github.com/eclipse-mosquitto/mosquitto](https://github.com/eclipse-mosquitto/mosquitto)

**Eclipse Mosquitto** is an open-source message broker that implements versions 5.0, 3.1.1, and 3.1 of the MQTT protocol. Developed originally by Roger Light, it is a lightweight tool designed for both low-power single-board computers and full servers, making it a staple in IoT messaging.

**Key Features and Tools:**
The project provides more than just the broker; it includes:
*   **Client Libraries:** C and C++ libraries for custom integration.
*   **Command-Line Utilities:** `mosquitto_pub` and `mosquitto_sub` for publishing and subscribing to topics, and `mosquitto_rr` for request-response messaging.
*   **Administrative Tools:** `mosquitto_ctrl`, `mosquitto_passwd`, and `mosquitto_signal` for managing security and broker behavior.

**Setup and Configuration:**
Installation is available via binary packages for most platforms or through source code. A "quick start" allows for immediate local testing, but the documentation emphasizes that remote access requires a configuration file to define listeners and security settings. For production environments, it is recommended to disable anonymous access and implement robust authentication.

**Building and Development:**
For those building from source, the project supports `Make` (Linux/Unix) and `CMake` (Windows/Mac), and it is available via the `vcpkg` dependency manager. While **cJSON** is the only mandatory dependency, optional features like TLS (OpenSSL), thread support (pthreads), and persistence (sqlite3) can be toggled during the build process.

**Resources:**
The project maintains a strong community presence with documentation available via man pages and its official website, [mosquitto.org](https://mosquitto.org/). It also offers a public test server for developers to verify their client implementations.

由于该车型早于 1996 年的 OBD-II 标准，它使用的是克莱斯勒专有的 **CCD（克莱斯勒碰撞检测）总线**。这种遗留协议是一种差分串行总线，难以使用现代诊断工具进行对接。Plummer 的目标是接入该总线以读取实时发动机数据。

**项目亮点包括：**

*   **硬件：** Plummer 使用了一个廉价的 Arduino 和一个基础的收发器电路来连接车辆线束。

*   **协议分析：** 通过将吉普车的原始十六进制转储数据输入 Claude，AI 能够识别特定的数据包。它成功解码了发动机转速（RPM）、冷却液温度、电池电压和车速的位结构。
*   **成果：** 在很短的时间内，AI 协助构建了一个功能性的终端仪表盘，用于显示实时车辆遥测数据。

这段视频展示了 **AI 代理在底层系统编程中**的强大实力。Plummer 总结道，AI 推理遗留协议和执行复杂位操作的能力显著降低了硬件逆向工程的门槛，将原本需要数天研究的任务变成了一次简短的对话式编程。

## 8. 你的房间可以像室外一样明亮 (2019)

**原文链接**: [https://www.benkuhn.net/lux/](https://www.benkuhn.net/lux/)

从塞内加尔搬到波士顿后，作者难以适应冬季阳光的匮乏，发现下午4点后就很难集中注意力。为了应对这一问题，他们尝试了高强度室内照明，最终将工作空间改造为一个模拟户外亮度的环境。

**解决方案与成效**
作者最初使用了一个30,000流明的“玉米头”LED灯泡，将室内光照水平从典型的50勒克斯（lux）提升到400勒克斯以上（相当于日出时的亮度）。这一改变显著提高了生产力，每天增加了一到两个小时的有效工作时间，并提升了家居环境的整体“愉悦感”。随后，他们对方案进行了改进，使用了21个等效100瓦的LED灯泡，以实现更好的光扩散效果和更高的显色指数（CRI）。

**核心见解**
*   **光照谱系：** 作者认为“季节性情绪失调”是一个谱系；大多数人在昏暗的室内环境中会感到更加困倦，而室内光线通常比户外暗100倍。

**实践注意事项**
作者指出，这些超高亮度的灯光会抑制睡意，因此必须在睡前几小时关闭。此外，用户应确保其灯具能够承受工业级灯泡的功率和重量。尽管存在风扇噪音或外观笨重等小缺点，作者仍认为高强度照明对于受季节性黑暗影响的人来说是一种具有变革性的工具。

## 11. Protomaps: Self-hosting map tiles has gotten cheap and easy

**原文标题**: Protomaps: Self-hosting map tiles has gotten cheap and easy

**原文链接**: [https://bruceroettgers.eu/blog/protomaps/](https://bruceroettgers.eu/blog/protomaps/)

本文由苏黎世联邦理工学院（ETH Zurich）计算机科学系学生 Bruce 撰写，探讨了 Protomaps 及其 PMTiles 格式，将其作为 Mapbox 等商业地图 API 的高性价比替代方案。

**问题与解决方案**
对于爆火或非商业项目，商业 API 的价格往往高得令人望而却步，一旦耗尽免费额度，便会收取高额费用。Protomaps 通过 PMTiles 解决了这一问题。PMTiles 是一种基于 HTTP Range 请求的单文件瓦片格式，使得地图可以托管在简单的云存储或 CDN 上，无需专门的后端服务器，从而实现了部署的便携性和低成本。

**使用 Bunny.net 实施**
作者推荐使用 Bunny.net 进行托管，因为它存储成本低（0.01 美元/GB）、拥有全球 CDN 并支持大对象缓存。他强调，托管一份 139GB 的世界地图每月仅需约 5 美元。相比 Mapbox 按每千次加载计费的固定模式，这种方法最多可便宜 100 倍，因为用户只需为实际传输的数据付费（典型的城市级缩放仅需约 0.00005 美元）。

**关键部署步骤：**
1. **获取数据**：下载每日更新的世界地图包，或使用 Protomaps CLI 提取特定区域以节省空间。
2. **上传数据**：使用 `rclone` 将文件流式传输到兼容 S3 的存储空间，以避免超时问题。
3. **优化配置**：将 CDN 配置为“针对大对象分发进行优化”，并设置安全措施（如 CORS 引荐来源和下载速度限制），以防止未经授权的使用或批量抓取。
4. **集成使用**：使用 MapLibre GL 配合 `pmtiles` npm 包嵌入地图。

总之，Protomaps 让开发者能够维持一个高可用、注重隐私且可扩展的地图解决方案，同时避开了传统 API 定价模型中的“成功税”。
