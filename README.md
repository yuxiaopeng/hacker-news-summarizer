## 2. 没有人是一座孤岛

**原文标题**: No Man Is an Island

**原文链接**: [https://borretti.me/article/no-man-is-an-island](https://borretti.me/article/no-man-is-an-island)

在《没有人是一座孤岛》一文中，作者指出，智力活动并非孤立的尝试，而是一种正在受到人工智能侵蚀的社群性行为。以软件工程为主要案例，作者观察到，虽然人工智能提高了生产力，但它同时也削弱了专业论述，并阻碍了人力资本的发展。

文章确定了持续智力工作的两项关键投入：共享的知识体系和动力。动力被进一步分为**内在动力**（转瞬即逝的学习欲望）和**外在动力**（为共同的人类项目做出贡献并获得同行认可的愿望）。作者认为，当内在兴趣减退时，外在动力是维持长期工作的“燃料”。

人工智能通过以下几种方式破坏了这一生态系统：
1.  **冗余性：** 当人工智能能够编写代码或证明定理时，人类对“公共资源”（如博客文章、教程或开源库）的贡献就变得多余了。
2.  **受众流失：** 随着人类停止学习技艺的底层逻辑，能够欣赏或在他人成果基础上进一步创作的同行群体也将不复存在。
3.  **技能贬值：** 从严谨的系统性思维转向与人工智能提示词的“随性互动”，导致了智力参与的浅薄化。

作者最后反驳了那种认为人工智能将通过过滤追名逐利者来“净化”智力生活的乐观观点。相反，由于人类是社交动物，需要感受到自己的贡献对他有用，人工智能创造的冗余威胁到那些让私人智力活动得以开展的社群。如果没有一个可以交流思想的“集市”，心灵的“私人花园”最终也将枯萎。

## 3. Cloudflare 收购 Deno

**原文标题**: Cloudflare acquires Deno

**原文链接**: [https://deno.com/blog/cloudflare](https://deno.com/blog/cloudflare)

2026年10月9日，Cloudflare宣布收购Deno，Deno全体团队将加入Cloudflare，将其工作成果与Workers和Durable Objects平台进行整合。此举标志着一项战略转型：从维护独立的运行时转向构建分布式应用的统一编程模型。

主要运营变化包括：
*   **Deno运行时：** 官方支持将持续一年，每月提供漏洞修复和安全更新。此后，团队将停止开发，Deno将完全转型为由社区主导的开源项目。
*   **Deno Deploy：** 该托管服务将在六个月内关闭。Cloudflare将为迁移至Cloudflare Workers的付费客户提供支持。
*   **JSR与开源：** JavaScript注册表（JSR）将保持运营，其基础设施将迁移至Cloudflare。`rusty_v8`的开发仍将继续，并计划将其整合进`workerd`。

Deno创始人Ryan Dahl解释称，此次转型源于简化开发“基础设施层”的愿景。团队未来的工作重点将是**celld**，这是一种基于Cloudflare Workers构建的编程模型，旨在简化分布式应用和AI代理框架的创建。通过将Deno的运行时创新与Cloudflare的全球网络及Durable Objects相结合，团队旨在建立一套无服务器执行标准，使其能够在Cloudflare网络和私有基础设施中无缝运行。
