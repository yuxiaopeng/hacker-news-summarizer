**原文链接**: [https://www.sdss.org/black-hole-mapper-release-20/](https://www.sdss.org/black-hole-mapper-release-20/)

斯隆数字巡天（SDSS）宣布发布第20次数据（DR20），这是其第五代巡天项目（SDSS-V）的一次里程碑式扩张。本次发布的核心是“黑洞制图者”（BHM）项目，该项目以前所未有的视角展现了整个宇宙历史上超大质量黑洞（SMBH）的生长与物理特性。

SDSS首次整合了来自北半球（阿帕奇点天文台）和南半球（拉斯坎帕纳斯天文台）的光学观测数据。DR20的一个主要亮点是SPIDERS项目，该项目将SDSS的光学光谱观测与eROSITA任务的X射线图谱相结合。通过此次协作，研究人员完成了约20万个X射线源的光学鉴定和距离测量，构建了迄今为止规模最大的此类数据集。

本次发布的主要科学发现包括：
*   **早期宇宙的生长**：在早期宇宙中，快速生长的巨型黑洞比此前预期的更为普遍。
*   **“隐藏”的黑洞**：数据显示，70%至90%的超大质量黑洞生长发生在厚重的尘埃和气体遮蔽之下，在传统的光学和紫外巡天中通常难以察觉。
*   **动态监测**：通过反响映射（Reverberation Mapping）和AQMES等项目，研究人员正在追踪类星体随时间的变化，以测量黑洞质量并观察剧烈的“变相”（changing-look）演化过程。

这些发现得益于全新的“机器人焦平面系统”，该系统实现了更快、更精确的观测。秉承SDSS开放科学的传统，DR20的所有数据（包括超过330万条光学光谱）均已通过各种在线工具和档案库向公众开放。此次发布标志着长达十年的国际合作成果，为全球科学界提供了一份关于高能宇宙的详尽普查报告。

**原文链接**: [https://www.theguardian.com/technology/2026/aug/06/new-mexico-court-meta](https://www.theguardian.com/technology/2026/aug/06/new-mexico-court-meta)

新墨西哥州法院裁定，Facebook和Instagram的母公司Meta需支付5.67亿美元，以应对其平台对儿童心理健康造成的负面影响。此项裁决源于今年3月的一场里程碑式审判，陪审团认定该公司在知情的情况下伤害未成年人，并隐瞒了有关儿童性剥削的信息。加上此前3.75亿美元的罚款，Meta在该州的赔偿总额已达9.42亿美元。

布莱恩·比德谢德法官指示，大部分资金（4.2亿美元）将拨给青少年治疗服务，其余资金将在未来五年内用于支持预防、筛查和宣传项目。除了经济处罚外，法院还强制要求该公司进行重大的运营变革：

*   **年龄验证：** Meta必须改进人工智能驱动的年龄确认工具，并尝试为13岁以下用户开发特定的预测模型。
*   **学校报告：** 该公司必须与学校合作，为教职员工创建一个标记违规未成年用户的门户网站。
*   **安全透明度：** Meta被要求建立信息展示页面，解释保护功能和最佳实践。
*   **数据删除：** 该公司必须删除从13岁以下用户处收集的所有个人信息。

该裁决标志着Meta首次因第三方在其平台上实施的行为而承担法律责任。此前，有关部门对Meta旗下应用如何被用于儿童性贩卖和诱拐进行了调查。新墨西哥州总检察长劳尔·托雷斯称赞这一决定是家庭的胜利，而Meta则宣布计划上诉，并为其安全记录辩护，对法院的调查结果表示异议。

法律专家表示，由于Meta在田纳西州和加利福尼亚州等地面临着涉及成瘾性设计和用户伤害的类似诉讼，此案可能成为引发“多米诺骨牌效应”的第一张牌。

## 4. 让 Postgres 的分析速度提升 300 倍：批处理、算子融合与 SIMD

**原文标题**: Making Postgres 300x faster for analytics: batching, operator fusion, and SIMD

**原文链接**: [https://malisper.me/how-we-made-postgres-hundreds-of-times-faster-the-query-engine/](https://malisper.me/how-we-made-postgres-hundreds-of-times-faster-the-query-engine/)

**pgrust v0.2** 的发布带来了显著的性能提升，声称其分析速度比**标准 PostgreSQL 快高达 300 倍**，甚至在某些基准测试中超越了 Clickhouse。文章指出，虽然 PostgreSQL 设计于 20 世纪 80 年代，当时磁盘 I/O 是主要瓶颈，但现代性能更多受限于 CPU 和内存吞吐量。

为了弥补这一差距，pgrust 查询引擎摒弃了传统的“火山模型”（Volcano model，即一次处理一行数据），并实现了三项核心优化：

1. **批处理 (Batching)：** 通过分块处理行（例如一次处理 1024 行），pgrust 减少了函数调用开销，并充分利用了 CPU 流水线。在一个求和查询示例中，批处理将执行时间从 1.3 秒缩短至 480 毫秒。
2. **算子融合 (Operator Fusion)：** 该技术将多个查询计划节点（如顺序扫描和聚合）合并到单个执行循环中，从而消除了将数据复制到中间缓冲区的需求。作者指出，即时编译 (JIT) 技术可用于针对任何任意查询自动实现这种“融合”。
3. **SIMD（单指令多数据流）：** 通过利用专用的 CPU 指令同时对多个数据点执行算术运算，引擎在硬件层面实现了大规模并行化。引入 SIMD 后，示例查询时间进一步缩短至 135 毫秒。

文章最后总结道，这些现代架构的转变——最小化内存分配、减少函数开销以及最大化 CPU 效率——使 pgrust 能够突破 PostgreSQL 的传统约束。通过专注于针对 CPU 受限场景的优化而非磁盘 I/O，pgrust 相比基础查询引擎实现提升了近 10 倍的速度，在分析任务中相比标准 Postgres 更是实现了超过 55 倍的巨大性能飞跃。

## 5. Show HN: Wyzer 编程语言

**原文标题**: Show HN: Wyzer Programming Language

**原文链接**: [https://github.com/Wyzer-Lang/wyzer](https://github.com/Wyzer-Lang/wyzer)

Wyzer 是一种新型静态类型、编译型且面向资源的编程语言，旨在将内存安全、并发处理和分布式系统统一在单一的所有权模型之下。它的首要目标是在不引入借用检查器（borrow checker）复杂性的前提下，提供类似 Rust 的安全保证，同时解决死锁和协议不匹配等高层分布式问题。

该语言依赖两大核心支柱：
1. **Perceus 内存模型**：借鉴自 Koka 和 Lean 4 等语言，通过精确的引用计数实现高效且无需垃圾回收（GC）的内存管理。
2. **编排式编程（Choreographic Programming）**：这种学术性方法允许开发者编写单一的“编排逻辑”，由编译器据此为多个服务生成安全、协调的代码，从而确保跨服务的正确性。

Wyzer 的哲学根植于简洁与显式。它将内存、线程和网络消息统一视为资源，并遵循一条准则：资源一旦使用，便不可再次使用。这种统一的方法消除了为管理不同安全领域而使用独立工具的需求。

在语法方面，Wyzer 的设计追求可读性与可预测性。变量默认为不可变（区分 `let` 与 `var`），错误通过 `Result` 类型和 `match` 表达式进行显式处理，且不存在隐藏的控制流或 `async/await` 的同步异步划分。

Wyzer 目前处于早期研究阶段，是一个正在寻求贡献者的开源项目。虽然其目标是达到生产级的性能和安全性，但创作者坦言目前仍有若干重大技术难题尚未解决。该项目设有 Discord 社区并提供文档，以帮助新用户尝试其独特的面向资源语义。

## 6. AMD收购Taalas，旨在通过将模型蚀刻在硅片上提升推理性能。

**原文标题**: AMD acquires Taalas to boost inference performance by etching models in silicon

**原文链接**: [https://www.theregister.com/systems/2026/08/06/amd-acquires-ai-chip-startup-taalas-to-boost-inference-performance-by-etching-models-into-silicon/5284344](https://www.theregister.com/systems/2026/08/06/amd-acquires-ai-chip-startup-taalas-to-boost-inference-performance-by-etching-models-into-silicon/5284344)

AMD has acquired Toronto-based AI startup Taalas in a strategic move to challenge Nvidia’s dominance in the AI hardware market. Unlike traditional GPUs that rely on High Bandwidth Memory (HBM), Taalas utilizes "model-specific integrated circuits" (MSICs) that etch model weights directly into the silicon.

**Key Technical Advantages**
Taalas’ technology promises a massive leap in inference performance. Its first test chip, the HC1, demonstrated the ability to serve Meta’s Llama 3.1 8B at nearly 17,000 tokens per second—approximately 48x faster than Nvidia GPUs. The upcoming second-generation HC2 chip targets 20 billion parameters per accelerator. By utilizing pipeline parallelism, AMD can support trillion-parameter models using just 50 accelerators, offering superior space and power efficiency compared to Nvidia’s LPX or Groq’s LPU systems.

**Strategic Integration**
AMD intends to integrate Taalas tech into its Instinct-based Helios racks. This creates a disaggregated architecture where GPUs handle compute-heavy prompt processing while Taalas chips manage high-speed token generation. While the technology requires a hardware "re-spin" to change a model—a significant downside regarding flexibility—the process involves changing only two metal layers, making it far cheaper than training frontier models.

**Market Impact**
The acquisition is aimed at high-performance "premium" inference services like AI agents and code assistants. The extreme speeds also enable "test-time scaling," allowing models to perform more complex reasoning without sacrificing response times. This tech is expected to be a major draw for infrastructure providers and model developers like OpenAI, Anthropic, and Meta. Subject to regulatory approval, the deal is slated to close in the fourth quarter of 2026.
