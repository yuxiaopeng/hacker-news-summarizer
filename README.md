## 4. 胶水可粘附于不粘表面，并可用乙醇擦拭干净。

**原文标题**: Glue bonds to nonstick surfaces and wipes clean with ethanol

**原文链接**: [https://cen.acs.org/materials/adhesives/glue-bonds-nonstick-surfaces-wipes-clean/104/web/2026/07](https://cen.acs.org/materials/adhesives/glue-bonds-nonstick-surfaces-wipes-clean/104/web/2026/07)

由高分子化学家相田卓三（Takuzo Aida）领导的东京大学研究团队开发出一种名为 **CyclicFP-fmoc** 的革命性小分子粘合剂，它能与聚四氟乙烯（PTFE）等不粘表面牢固结合。

与通常表现为脆性（如环氧树脂）或低粘性（如胶带）的传统聚合物粘合剂不同，CyclicFP-fmoc 兼具高粘合强度和延展性。在搭接剪切拉伸测试中，该粘合剂在未经处理的 PTFE 表面上表现出 1.3 MPa 的强度，显著优于商用环氧树脂和硅胶。这种粘合剂的效能源于其与基材之间的界面氟-氟（F-F）相互作用，以及粘合剂分子内部氢键和 $\pi$-$\pi$ 堆积的共同作用。

该粘合剂的一个关键特性是其可持续性。只需使用乙醇简单冲洗，即可将其从表面彻底去除且不留残渣。由于该粘合剂利用非共价键结合，回收的单体可以多次重复使用而性能不减。这一特性有助于粘合组件的简便分离与回收，而这在目前使用永久性聚合物粘合剂的情况下是难以实现的。

尽管性能优异，但来自马里兰大学和加州大学伯克利分校的外部专家提醒，该分子的环境影响仍需进一步研究。鉴于其含氟结构，人们担心它可能属于被称为“永恒化学品”的全氟和多氟烷基物质（PFAS）家族。在将该粘合剂投入实际应用之前，确定其生态归宿将是至关重要的一步。

## 8. 从代码库中移除 React.js 并改用 Htmx 实现 UI 交互 (2023)

**原文标题**: Removing React.js from the codebase and adapting Htmx for UI interactivity (2023)

**原文链接**: [https://misago-project.org/t/removing-reactjs-from-the-codebase-and-adapting-htmx-for-ui-interactivity/1267/](https://misago-project.org/t/removing-reactjs-from-the-codebase-and-adapting-htmx-for-ui-interactivity/1267/)

In 2023, the Misago forum project announced a transition from React.js to HTMX to address the complexities of its hybrid architecture. Currently, Misago renders pages twice: first as Django templates for initial delivery and then as React components that overwrite the HTML to provide interactivity.

This "double-implementation" approach creates several significant problems:
*   **Redundancy:** Developers must maintain views, templates, and translation files in both Django and React.
*   **Performance Issues:** Large JavaScript payloads and JSON serialization overhead slow down response times and tax older mobile devices.
*   **User/Developer Friction:** Users experience a "flash" when React replaces server-rendered HTML, and plugin developers are forced to learn two distinct stacks to customize the UI.

After considering alternatives like a pure React SPA or Next.js, the author concluded that forum software—which relies on isolated interactive elements like moderation tools and polls—does not require a heavy frontend framework. 

Instead, Misago is adopting **HTMX**, a lightweight library that allows for "dynamic islands" of interactivity. HTMX enables the server to send specific snippets of HTML to be swapped into the page via declarative attributes, similar to modern Turbolinks. This shift returns the project to a server-centric model, eliminating the need for complex JSON APIs and duplicate frontend logic while maintaining a smooth, modern user experience and simplifying the codebase for contributors and plugin creators.
