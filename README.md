## 5. 纽约市“一键取消”新规正式生效。

**原文标题**: NYC's "Click to Cancel" rule is now in effect

**原文链接**: [https://www.nyc.gov/main/click-to-cancel](https://www.nyc.gov/main/click-to-cancel)

纽约市已实施“点击取消”（Click to Cancel）规则，这是全美首项旨在消除“订阅陷阱”的市政法规。该规则将于2026年10月1日生效，规定若企业能让用户轻松注册服务，则必须提供同样简单的取消方式。

**主要条款**
该规则由消费者和工人保护局（DCWP）负责执行，要求企业：
*   **方式对等：** 提供简单明了的取消流程，且必须使用与注册时相同的方法（例如：若在线注册，则必须能够在线取消）。
*   **透明化：** 清晰说明订阅条款，披露消费者权益，并就自动续订或条款变更提醒用户。
*   **禁止收取退回费：** 禁止向消费者收取寄回最初免费提供的物品的费用。

**执行与处罚**
凡被发现违反这些规定的企业，将面临525美元起步的民事罚款，并可能被要求向受影响的消费者退款。

**投诉流程**
消费者如遇到阻碍，例如在线注册后被强制要求通过电话取消、取消处理延迟或收到未订购的产品，可提交投诉。投诉可通过在线、邮寄或传真方式提交。投诉提交后，DCWP将审查案件，并可能指派调解员协助消费者与企业达成和解。

该倡议由市长佐兰·马姆达尼（Zohran Mamdani）发起，旨在保护纽约市民免受企业为维持不必要订阅而设置的繁琐及耗时障碍的影响。
