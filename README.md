**原文标题**: Cloudflare Quick Tunnels

**原文链接**: [https://try.cloudflare.com/](https://try.cloudflare.com/)

Cloudflare Quick Tunnels 是一款开发者工具，旨在通过 Cloudflare 的全球边缘网络，将本地服务器立即转换为公开且加密的 URL。用户只需运行一条简单的命令——`cloudflared tunnel --url http://localhost:[端口]`——即可将其本地环境暴露给互联网，而无需 Cloudflare 账户、DNS 配置或开放任何入站防火墙端口。

**核心功能与优势：**
*   **零摩擦：** 无需注册或配置文件。隧道是临时性的，仅在进程运行时存在，不会留下任何需要清理的痕迹。
*   **增强的安全性：** 采用仅出站连接方式连接至 Cloudflare 最近的边缘节点。流量会自动受到 TLS 加密和 DDoS 过滤的保护。
*   **为 AI 代理优化：** 洞察到“代理时代”的到来，该工具现在提供结构化 JSON 输出。这使得编码代理和自动化工作流能够以编程方式捕获主机名和健康状态，而无需进行复杂的日志解析。
*   **全球覆盖：** 利用 Cloudflare 遍布全球 335 多个边缘城市的网络，确保世界各地的团队成员或 Webhook 都能实现低延迟访问。

**常见使用场景：**
Cloudflare Quick Tunnels 非常适合测试 Webhook（如 Stripe 或 GitHub）、与团队成员共享实时预览、运行评估测试框架，以及为 AI 代理提供用于测试循环的可访问地址。

**快速入门：**
要使用该服务，开发者只需通过包管理器安装 `cloudflared` CLI，运行本地应用程序，并执行隧道命令。系统会立即生成一个唯一的 `trycloudflare.com` URL，在本地机器与公共网络之间建立起一座安全的桥梁。

## 2. 光子发射引导的激光故障注入实现 RP2350 安全调试

**原文标题**: Photon-Emission-Guided Laser Fault Injection Enables RP2350 Secure Debug

**原文链接**: [https://donjon.ledger.com/blog/rp2350-secure-debug-laser-fault-injection/](https://donjon.ledger.com/blog/rp2350-secure-debug-laser-fault-injection/)

研究人员已成功演示了对树莓派（Raspberry Pi）RP2350 微控制器安全保护措施的绕过，专门针对其安全调试（Secure debug）和 TrustZone 环境。尽管该芯片使用一次性可编程（OTP）存储器来永久禁用调试功能，研究人员仍找回了用于 RP2350 黑客挑战赛的 128 位密钥。

此次攻击重点针对 **`DEBUGEN` 寄存器**，该寄存器充当 `DEBUG_DISABLE` 标志的硬件覆盖开关。与其他关键安全 OTP 字段不同，该寄存器缺乏位冗余，使其成为故障注入的潜在目标。为了定位负责这些位的特定晶体管，团队使用了 **光发射显微镜（PEM）**，该技术可检测开关晶体管发出的红外光。这使他们能够精确绘制出进行 **激光故障注入（LFI）** 所需的位置。

通过对识别出的部位施加精确的激光脉冲，研究人员翻转了重新启用具有安全属性的存储器访问端口（Mem-AP）所需的位。为了绕过运行时的软件锁，他们通过 RP-AP 接口利用了 **“救援复位”（rescue reset）**。这在固件对秘密 OTP 页面应用“软锁定”之前停止了启动过程，使得新启用的调试器可以读取数据。

主要发现包括：
*   **硬件漏洞：** `DEBUGEN` 寄存器提供了一个关键的覆盖路径，可以通过硬件故障进行利用。
*   **锁定失效：** 旨在防止软件写入的 `DEBUGEN_LOCK` 功能无法防止激光诱导的状态变化。
*   **准入门槛高：** 该攻击非常复杂，需要物理接触、对芯片进行破坏性的“背面开封”，以及价值约 **25 万美元** 的专业实验室设备。

这项研究强调了即便实施了强大的逻辑安全措施，防御物理侧信道攻击依然困难重重。

朝鲜2017年的核试验是其迄今为止规模最大的一次，对万塔山地区产生了深远而持久的地质影响。根据发表在《地震研究快报》上的一项研究，这次估计威力达25万吨当量的爆炸引发了一系列地震活动，并在初始爆炸后的数年里持续不断。

通常情况下，人造爆炸不会产生天然地震所特有的持续性余震。然而，2017年的试验威力巨大，以至于改变了山体的地壳结构。爆炸产生了一个巨大的地下空腔，该空腔在随后不久便发生坍塌，并引发了数十次微震。中国科学技术大学和美国地质调查局的研究人员利用先进的地震监测和卫星数据识别出了这些延迟信号，且这些信号至少持续到了2020年。

这些发现对国际核监测具有重要意义。区分天然构造活动与核试验的后续影响，对于验证条约遵守情况至关重要。此外，持续的不稳定性表明，丰溪里核试验场可能已经在地质上变得不稳定，这可能会使该地点未来的高当量试验变得复杂甚至无法进行。

## 9. Cache-to-Cache：大语言模型间的直接语义通信

**原文标题**: Cache-to-Cache: Direct Semantic Communication Between Large Language Models

**原文链接**: [https://arxiv.org/abs/2510.03215](https://arxiv.org/abs/2510.03215)

**"Cache-to-Cache: Direct Semantic Communication Between Large Language Models"** (published at ICLR 2026) proposes a novel paradigm for multi-LLM systems that replaces traditional text-based communication with direct KV-Cache sharing.

**The Problem:**
Current multi-LLM systems rely on text to exchange information. This approach suffers from two primary drawbacks:
1.  **Information Loss:** Internal, high-dimensional semantic representations are "flattened" into token sequences, losing rich nuance.
2.  **High Latency:** Models must wait for token-by-token generation from the source model before the target model can begin processing.

**The Solution (C2C):**
The authors introduce **Cache-to-Cache (C2C)**, which enables models to communicate via their internal KV-Caches. The system employs:
*   **Neural Projection and Fusion:** A neural network projects the source model’s KV-Cache into the target model’s latent space, allowing for direct semantic transfer.
*   **Learnable Gating Mechanism:** A gate automatically selects which layers of the target model should receive the transferred cache to maximize benefit.

**Key Findings and Performance:**
*   **Increased Accuracy:** C2C achieves an average accuracy improvement of 6.4–14.2% over individual models and outperforms text-based communication by 3.1–5.4%.
*   **Significant Speedup:** By bypassing the need for explicit intermediate text generation, C2C delivers an average **2.5x reduction in latency** compared to the text communication paradigm.
*   **Semantic Richness:** Oracle experiments confirmed that enriching KV-Cache semantics improves response quality without needing to increase cache size.

**Conclusion:**
C2C demonstrates that LLMs can collaborate more effectively and efficiently by communicating through their internal representations rather than natural language, providing a faster and more accurate framework for multi-model intelligence.
